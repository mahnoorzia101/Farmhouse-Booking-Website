# 🏡 Farmhouse Booking System  

A full-stack web application built using the **MERN stack** (MongoDB, Express.js, React, Node.js) that allows users to explore and book farmhouses in Karachi.  

---

## 🚀 Features
- User and farmhouse owner **registration & login**  
- Farmhouse **listing with images, price, location, and ratings**  
- **Search by location**  
- **Booking system** with date availability (no double bookings)  
- **Reviews/Experiences** page  
- **About page** with dummy company details  
- **Responsive UI** built with TailwindCSS  

---

## 🛠️ Tech Stack
**Frontend:** React.js, TailwindCSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB (Mongoose ORM)  
**Other Tools:** Axios, React Router
